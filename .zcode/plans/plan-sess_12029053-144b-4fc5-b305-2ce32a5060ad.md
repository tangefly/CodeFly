# 课程时间可并行安排任务 + 课程与任务并列显示

## Context

用户上课不听，希望课程时间**既保留在日程表上，又能被任务块占用**；展示上要求**课程名和任务名并列显示在同一行**，一眼看清"这段时间上什么课、做什么任务"。

当前代码做不到：`scheduler.ts` 的 `buildDayPools`（`apps/server/src/schedule/scheduler.ts:276-282`）把所有固定事件从可用时段硬性扣除，`ScheduleFixedEvent` 类型也没有"该时段可安排任务"的字段。

**方案**：
1. 固定事件加 `busy` 标志（默认 `true` 保持现状、老数据兼容）；`busy: false` 的课程不再被调度器排除，任务块可排在其时段内。
2. Agenda 构建时把"排进非忙碌课程时段的任务块"**挂到该课程条目上**（`parallelBlocks` 字段），所有渲染端（Web / PNG / agent 文本）都以**一行并列**的方式显示课程和任务。

## 改动（按依赖顺序）

### 1. Protocol 包 `packages/protocol/src/`
- `types.ts:547` `ScheduleFixedEvent` 加必填 `busy: boolean`（必填让编译器指出所有构造点）
- `types.ts:564` `ScheduleFixedEventInput` 加 `busy?: boolean`
- `types.ts:724` `ScheduleAgendaItem` 加：
  - `busy: boolean | null`（fixed 项携带、task 项 `null`，仿 `priority` 模式）
  - `parallelBlocks?: Array<{ blockId, title, start, end, status, priority }>`——非忙碌课程时段内排入的任务块
- `schemas.ts:311/335` 两个 fixed event schema 各加 `busy: z.boolean().optional()`

### 2. 调度器 `apps/server/src/schedule/scheduler.ts`
- `buildDayPools` 的 carve-out 循环（276 行）加 `if (!event.busy) continue;`——非忙碌课程不再从可用时段扣除（gap 缓冲也不扣）；更新注释

### 3. 存储 `apps/server/src/schedule/store.ts`
- `normalizeFixedEvent`（385）：`busy: asBoolean(raw.busy, true)`（helper 已在 136-138 行）→ 老数据默认 true
- `createFixedEvent`（1071）：`busy: input.busy ?? true`
- `updateFixedEvent`（1089）：`if (patch.busy !== undefined) event.busy = patch.busy;`
- `upsertFixedEvent`（1161）：入参加 `busy?: boolean`，两处委托调用转发
- 迁移字面量（约 1307）：补 `busy: true`
- `assertNoOverlap`（2014-2026）：固定事件循环加 `if (!event.busy) continue;`——手动移动任务块到非忙碌课程时段不再报 `BLOCK_OVERLAP` 409

### 4. Agenda 合并与统计 `apps/server/src/schedule/agenda.ts`（本次展示方案的核心）
- 从 `agendaItemsForDay`（70-114）中导出纯函数 helper（如 `pairParallelBlocks(events, blocks, date)`）：把与非忙碌课程时间重叠的任务块分配给该课程（与多个课程重叠时取重叠最大者）
- `agendaItemsForDay`：非忙碌课程条目带 `busy: false` + `parallelBlocks`；被挂走的任务块**不再单独生成条目**；其余不变
- `freeMinutesForDay`（142-149）：跳过 `busy === false` 的课程本体；但其 `parallelBlocks` 的时间仍要扣减（该时段被任务占用）
- `buildScheduleAgenda` 的 `plannedMinutes`（186-189）：非忙碌课程本体不计入，其 `parallelBlocks` 按任务时长计入

### 5. Agent 工具 `apps/server/src/schedule/tools.ts`
- `fixedEventUpsertArgs`（484-496）加 `busy: z.boolean().optional()`；`fixedEventUpsert`（1328-1338）转发
- `formatFixedEvent`（167-179）：busy=false 时标注 `· 时段可安排任务`
- `formatPlan`（236-288）：复用第 4 节的 pairing helper，课程行输出 `▣ 09:00-11:00 高数（可并行）∥ 期末复习 09:00-10:30（待办）`
- 工具描述（748-812）更新 `fixed_event_upsert` 的 busy 说明

### 6. 运行时上下文 `apps/server/src/schedule/service.ts`
- 固定事件条目（207-219）加 `· 可并行` 标注，让 agent 规划时知道该时段可用

### 7. Agent 提示词 `apps/server/src/schedule/prompt.md`
