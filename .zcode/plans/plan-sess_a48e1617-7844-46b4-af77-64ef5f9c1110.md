# 日程改版：滚动 7 天 + 按天议程

## Context

现在的日程模块默认按日历周（周一~周日）组织：`ScheduleStore.overview()` 用 `mondayOf(today)` 取一周，`plan_schedule` 也按周生成，所以周六打开时"最近一周"只剩两天。UI 又是"任务 × 7 天"的课程表矩阵，空单元格多、看不出一天的真实顺序。目标：

1. "最近一周"统一为**今天 0 点起未来 7 天**（today ~ today+6），今天已经过去的时段不再排任务；面板可前后翻 7 天，并提供"回到今天"。
2. 面板、对话里的工具卡片、导出的 PNG/邮件统一改成**按天议程卡片**：顶部 7 天负载条，主体是每天一张卡片，内部按真实时间顺序列出固定安排和任务块。
3. 存储层继续按 ISO 周分片（不改历史数据），读取时把窗口内跨周的计划合并成一个视图。

## 1. Protocol（`packages/protocol/src/types.ts`、`schemas.ts`）

新增展示/窗口类型（存储在 `SchedulePlan` 里按周不变）：

```ts
interface ScheduleWindow {
  startDate: string; endDate: string; timezone: string;
  blocks: ScheduleBlock[];
  unscheduled: ScheduleUnscheduledTask[];
  warnings: string[]; notes: string;
}
interface ScheduleAgendaItem {
  id: string; kind: "fixed" | "task"; title: string;
  start: string; end: string; status: ScheduleBlockStatus;
  actualMinutes: number | null; priority: SchedulePriority | null;
  location: string; note: string;
}
interface ScheduleAgendaDay {
  date: string; weekday: string; items: ScheduleAgendaItem[];
  plannedMinutes: number;      // 固定 + 任务块（跳过的不算）
  freeMinutes: number | null;  // 非工作日为 null；今天从"现在"起算
}
interface ScheduleAgendaModel {
  startDate: string; endDate: string; timezone: string; today: string;
  generatedAt: string; days: ScheduleAgendaDay[];
  summary: SchedulePlanSummary;
  unscheduled: ScheduleUnscheduledTask[]; warnings: string[]; notes: string;
}
```

- `SchedulePlanSummary` 的 `weekStart/weekEnd` → `rangeStart/rangeEnd`。
- `ScheduleOverview` 的 `weekStart/weekEnd/plan` → `rangeStart/rangeEnd/window: ScheduleWindow | null/agenda: ScheduleAgendaModel`（agenda 始终有 7 天，即使没有计划）。
- `scheduleOverviewQuerySchema`：`week_start` → `start_date`。
- `scheduleEmailSendSchema`：`week_start` → `start_date?` + `days?`。

## 2. 时间与调度（`time.ts`、`scheduler.ts`）

- `time.ts` 新增 `nowMinutesInTimezone(timezone)`、`rangeEndOf(start, days)`；`mondayOf/weekEndOf` 保留给存储层。
- `scheduler.ts` 的 `SchedulerInput` 增加 `nowClock?: string`。`buildDayPools` 在 `date === today` 时把工作区间起点抬到 `max(workStart, 现在时间向上取整到 5 分钟)`；若现在已过 `workEnd`，当天容量为 0。这样"未来 7 天"不会排到今天上午。

## 3. Store（`store.ts`）

- 新增 `getWindow(startDate, days = 7): ScheduleWindow | null`：从所有按周存储的 plan 中收集 `date ∈ [start, end]` 的 blocks；合并与窗口相交的周计划的 `unscheduled`（按 taskId 去重）、`warnings`（去重）、`notes`（非空拼接）。有相交的已存计划就返回 window（允许 0 blocks，用于只有固定课程的窗口）。
- 新增 `summarizeWindow(window)`；`summarize(plan)` 改为输出 `rangeStart/rangeEnd`（取 plan 的 weekStart/weekEnd）。
- `overview(startDate?)`：默认 `startDate = today`，窗口 7 天；返回 `rangeStart/rangeEnd/window/agenda`。传日期时只改变窗口起点，不强制周一。
- `getPlan/applySchedule/updateBlock` 等按周存储逻辑不变。

## 4. 议程构建（新增 `apps/server/src/schedule/agenda.ts`）

`buildScheduleAgenda({ window, tasks, fixedEvents, preferences, startDate, endDate, today, nowClock })`：

- 逐日生成 7 天：合并当天固定安排（weekly/once）与 window blocks，按 `start` 排序（同时间固定安排优先）。
- 每条 item 带 kind/title/time/status/priority/location/note/actualMinutes。
- `plannedMinutes`：固定事件时长 + 非 skipped block 时长。
- `freeMinutes`：工作时段减去 breaks，再减去当天固定安排和块在此时段内的并集；`today` 从当前时间起算；非工作日为 null。
- 这个模型同时供 UI、工具卡片、PNG 使用，避免三套逻辑。

## 5. 工具与提示词（`tools.ts`、`prompt.md`、`service.ts`）

- 参数统一为滚动窗口：
  - `plan_get`、`plan_schedule`、`plan_render`、`plan_email`：`from_date?`（默认今天）+ `days?`（1..21，默认 7）；`plan_schedule` 保留 `task_ids/allow_spill/notes`，`plan_replan` 保持现有 `from_date/days`。
  - 删除 `week_start` 参数。
- `runPlanner`：`startDate = max(from_date, today)`，`windowEnd = startDate + days - 1`，`allow_spill` 时排期范围再 +7 天；fixed-only 检查改为扫描整个窗口；把 `nowClock` 传给 `generateSchedule`；planMeta 挂到窗口起点所在的 ISO 周（overview 读取时能合并到）；渲染请求的 7 天窗口，内容里注明"另有 N 个时段排在窗口之后"。
- `formatPlan` 改为按窗口日期逐日输出（现有按日期分组的逻辑基本可复用），使用 window blocks 而不是单个周 plan。
- `planResultMeta` 改为接收 window，生成 `agenda` + `window` 放进 tool meta。
- `plan_get` 返回 window/agenda；`plan_render/plan_email` 用 window；`block_update` 返回包含该 block 的 7 天窗口。
- `prompt.md`：明确"最近一周 = 今天起未来 7 天，不是周一到周日"；plan_schedule/plan_replan 默认从今天起；禁止把任务排到已经过去的时间；总结按"日期 → 时间顺序"输出。
- `service.ts` 运行时上下文：`Rolling window: start ~ end`，计划统计改读 `overview.window`。

## 6. PNG / 邮件 / 路由

- `render.ts`：用 `renderAgendaPng` 替换 `renderWeekPng`。竖版 ~820px 宽：
  - 标题 `未来 7 天日程 · start ~ end`，副标题时区/生成时间；
  - 摘要条；
  - 每天一个 section：日期头（周几 + 日期 + 当天时长/项数），下面按时间排列的条目行（时间 | 标题 | 状态/优先级/地点），无安排显示"无安排"，底部显示空闲时间；
  - 页脚：未排期、提醒、备注。
  - 继续用现有 `truncate/wrap/escapeXml` 和 sharp；文件名保持 `week-{start}-...png`，路由正则不变。
- `email.ts`：`sendPlan` 参数改为 `window/summary/agenda`，主题改为"CodeFly 未来 7 天日程"，正文按天列出安排（文本 + HTML）。
- `routes/schedule.ts`：overview 读 `start_date`；email send 读 `start_date/days`，用 `getWindow` + `renderAgendaPng`；audit 字段改为 `rangeStart`（`AuditDrawer` 兼容旧 `weekStart`）。

## 7. Web

- `lib/api.ts`：`scheduleOverview(startDate?)` 用 `start_date`；`sendScheduleEmail(startDate?, days?)` 用新 body。`lib/store.ts` 只改参数名/透传。
- 新增 `components/schedule/ScheduleAgenda.tsx`：
  - 顶部 7 天负载条：每天显示周几/日期/计划时长/项数，今天高亮；
  - 主体 `sm:grid-cols-2` 的日卡片：日期头、按时间排序的条目（左侧时间、右侧标题与徽标，固定=青色、任务=蓝色、完成=绿色、跳过=删除线）、底部"空闲约 X / 已排满 / 休息日"；
  - 空窗口显示占位提示；提供 `compact` 变体给对话里的工具卡片。
- `SchedulePanel.tsx`：`weekStart` state → `rangeStart`；上一/下一按 ±7 天；新增"回到今天"；tab "本周计划" → "7 天日程"；用 `<ScheduleAgenda agenda={overview.agenda} />` 替换 `WeekTable`；warnings/unscheduled 从 `overview.window` 读；邮件发送传 `overview.rangeStart`。
- `ScheduleToolCard.tsx`：删掉本地 `PlanTable` 与 row 类型，改用 `data.agenda` 的 `ScheduleAgenda`（compact）。
- 同步更新 `ScheduleSidebar.tsx`、`ScheduleTopBar.tsx`、`AgentTimeline.tsx` 里的 `weekStart/weekEnd/plan` 引用（改为 range/window；文案"未来 7 天"）。
